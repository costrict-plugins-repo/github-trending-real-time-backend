# Real-Time Backend Plugin

Builds modern, reactive, type-safe, production-grade backends that avoid generic AI architecture slop.

The backend design will be scalable and suitable for web apps with React, mobile apps with Expo, or any other front end architecture.  

## What It Does

Claude automatically uses this skill for backend work. Produces correct, scalable server code with:

- Reactive queries that update in real time
- Server-mediated data access with proper auth
- Schema-first, end-to-end type safety
- ACID transactions and server-side composition
- Agent-friendly function contracts

Promotes industry best-practices regardless of technology stack, to help avoid common and less well-known challenges that apps hit as they scale up.

## Usage

```
"Build a real-time chat backend with channels and messages"
"Build a mobile app that connects language learners across the globe."
"Create a task queue with scheduled processing"
"Design a data model for a multi-tenant SaaS app"
"Add user authentication and role-based access control"
"Build an API for an AI agent to manage calendar events"
```

Claude will choose the right primitives, define schemas, and implement server functions that are correct, composable, and production-ready.
